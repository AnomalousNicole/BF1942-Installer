# branding/

Optional artwork for the left panel of the installer's Welcome and Finish pages. Without it, the installer uses Inno Setup's default image.

Add 24-bit BMP files with these names. Only `WizardImage100.bmp` is needed; the other sizes keep the image sharp when Windows display scaling is above 100%.

| File | Windows scaling | Size (px) |
|---|---|---|
| `WizardImage100.bmp` | 100% | 164 × 314 |
| `WizardImage125.bmp` | 125% | 192 × 386 |
| `WizardImage150.bmp` | 150% | 246 × 459 |
| `WizardImage175.bmp` | 175% | 273 × 556 |
| `WizardImage200.bmp` | 200% | 328 × 604 |
| `WizardImage225.bmp` | 225% | 355 × 700 |
| `WizardImage250.bmp` | 250% | 410 × 797 |

`*.bmp` files here are git-ignored. Only use artwork you have the right to use.
