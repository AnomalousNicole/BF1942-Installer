Battlefield 1942 Troubleshooting

For the Battlefield 1942 & Expansions installer

Many problems below are fixed in Battlefield 1942 Options, which the installer adds to the Start menu (and to your desktop, unless you unticked it). It switches the graphics fix between DXVK and dgVoodoo2, turns BF42++, 3D audio, Higher resolution UI, Borderless1942, the Battle of Britain siren and the Compatibility Profile on or off, changes the font size, sets the game to your screen's resolution and can generate a CD key. Close the game, make your changes and click Apply.

For DataField42, Battlefield Rich Presence and PunkBuster, run the installer again and choose Custom. It installs over your existing game in the same folder, so you don't need to uninstall first. Running the installer again also puts back every fix, with the choices you make in it.

The game folder is C:\EA Games\Battlefield 1942 unless you picked a different one during setup. This guide is in its manual folder, next to the game manual.

1. The game shows a black screen

The installer picks one of two graphics fixes for your card:

Graphics fixUsed for
DXVKGraphics cards with full Vulkan 1.3 support, which is most cards from 2016 or later
dgVoodoo2Everything else, including AMD Radeon RX 400 and RX 500 cards

A black screen at start-up almost always means DXVK was installed on a card or driver that can't run it.

Check

Open the game folder and look for BF1942_d3d9.log. If it contains No adapters found, DXVK can't use your graphics card.

Fix

  1. Update your graphics driver from AMD, NVIDIA or Intel, restart the PC and try again.
  2. Still black? Switch to dgVoodoo2. Open Battlefield 1942 Options, pick dgVoodoo2 under Graphics fix and click Apply. Check my graphics card runs the same check as setup and picks the right one for you.

To go back to DXVK later, pick DXVK in the same place.

2. The game crashes or closes by itself

  1. Install the Compatibility Profile. Open Battlefield 1942 Options, turn on Compatibility Profile and click Apply. It applies the Windows compatibility fixes recommended by PCGamingWiki. Only use it if the game crashes without it.
  2. Turn off overlays for the game, such as the Discord, Steam, NVIDIA or AMD overlays, and on-screen display tools like MSI Afterburner or RivaTuner. Old games often crash when one of them hooks in.
  3. Check your antivirus. If it has quarantined files from the game folder, restore them, add an exclusion for the game folder, and run the installer again to put back anything that was removed.
  4. Don't set compatibility mode yourself. If you ticked Run this program in compatibility mode in the properties of BF1942.exe or a shortcut, untick it. The installer already sets up what the game needs.

3. Resolution, screen and text size

  • Wrong resolution: setup sets the game to your main screen's resolution and refresh rate at the time of install. If you have changed screens since, click Use my screen's resolution in Battlefield 1942 Options, or pick a resolution in the game under Options > Video.
  • Game opens on the wrong screen: make the screen you want to play on the main display in Windows (Settings > System > Display), then click Use my screen's resolution in Battlefield 1942 Options.
  • Text too small or too big: pick a different Font size in Battlefield 1942 Options.

  • Blurry menus: turn on Higher resolution UI in Battlefield 1942 Options for sharper menus and HUD.

4. Alt-Tab minimizes the game

That's how fullscreen works in Battlefield 1942. For a game you can switch away from without it minimizing, open Battlefield 1942 Options and turn on Borderless1942 (64-bit Windows only). Then start the game with the Battlefield 1942 (Borderless) shortcut on your desktop.

5. No sound, or sound from the wrong device

  • The game uses your Windows default playback device and picks it when it starts. Plug in your headset or speakers and set them as the default (right-click the speaker icon on the taskbar, Sound settings) before starting the game. Changing the device while the game is running doesn't move the sound.
  • 3D positional audio (DSOAL and OpenAL Soft) works best with headphones. If the sound still doesn't work, try turning 3D positional audio off in Battlefield 1942 Options.
  • Check that the game isn't muted in the Windows Volume mixer.

6. Can't see or join servers

  • Server shortcut: if your installer added a shortcut for a server to the desktop, it skips the intro and connects straight to that server.
  • Windows Firewall: the first time you play online, Windows asks whether to allow Battlefield 1942 on networks. Click Allow. If you clicked Cancel, go to Windows Security > Firewall & network protection > Allow an app through firewall, and tick Battlefield 1942 (BF1942.exe) for Private and Public.
  • Kicked with a PunkBuster message: that server needs PunkBuster. Run the installer again, choose Custom and tick Punkbuster42. When its window opens, click Install/Repair, then close the window to let setup finish.
  • The game says your CD key is missing or invalid: open Battlefield 1942 Options and click Generate a CD key. The button only works when no valid key is registered.
  • Missing map or mod when joining: the DataField42 extra (choose Custom) downloads missing maps and mods automatically when you join a server.

7. Problems during setup

  • "Windows protected your PC": click More info, then Run anyway. The installer isn't code-signed, so Windows shows this for it.
  • Setup asks whether to install DXVK or dgVoodoo2: its graphics check couldn't run, which is usually an antivirus blocking it. Pick DXVK (the default) for most graphics cards from 2016 or later, or dgVoodoo2 for older cards and AMD RX 400/500 cards. If you get a black screen afterwards, see section 1. To stop the antivirus blocking the check next time, add an exclusion for the setup file and the game folder.
  • PunkBuster window: setup waits while the PunkBuster window is open. Click Install/Repair, then close that window, and setup will finish.
  • Install folder: EA Games\Battlefield 1942 is always added to the folder you choose. For example, D:\Games becomes D:\Games\EA Games\Battlefield 1942.
  • Setup failed or stopped: every run writes a log file. Press Win + R, type %TEMP% and press Enter. The newest Setup Log file describes the last run. Include it when you ask for help.

8. Uninstalling

Go to Settings > Apps > Installed apps, find Battlefield 1942 & Expansions and click Uninstall. It removes the game folder and everything the installer added, including the CD key if setup or Battlefield 1942 Options created it. DirectX, Visual C++ and DirectPlay stay, because other games may use them. PunkBuster's background services are only removed if no other PunkBuster game is found on your PC.

Uninstalling deletes the whole game folder, including anything you added to it yourself, such as screenshots, extra maps or mods. Copy anything you want to keep somewhere else first.

9. Still stuck? Getting help

Ask whoever gave you the installer, or the community you play with.

Please include:

  • Your Windows version and graphics card
  • Whether setup asked you to choose between DXVK and dgVoodoo2, and what you picked
  • What went wrong, and any error message you saw (a screenshot helps)
  • If setup failed: the newest Setup Log file from %TEMP% (see section 7)
  • If you get a black screen: BF1942_d3d9.log from the game folder
